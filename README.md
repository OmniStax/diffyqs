# Differential Equations for Engineers

The OmniStax edition of *Differential Equations for Engineers*, from Jiří Lebl.
Read it at https://omnistax.andrewchen14250.workers.dev/. The app that reads it, the shared tools and the rules for building a book are in [BlastWind/OmniStax](https://github.com/BlastWind/OmniStax); clone this repository into that one's `omnistax-content/` folder (`npm run books` there does it).
